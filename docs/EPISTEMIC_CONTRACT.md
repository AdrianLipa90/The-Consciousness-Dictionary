# Epistemic contract

The dictionary deliberately separates:

| Status family | What it means | What it does **not** mean |
|---|---|---|
| Definition | A declared vocabulary rule | Empirical truth of an ontology |
| Established math/physics | Standard mathematical/physical result in its legitimate domain | Automatic applicability to consciousness |
| Implemented | Exists in executable software | Phenomenality or physical realization |
| Model definition | Internal definition within the proposed formalism | Established natural law |
| Constitutive hypothesis | The theory's substantive identity/constitution claim | Derived theorem or settled evidence |
| Hypothesis | Testable proposed relation | Confirmation |
| Interpretation | Meaning-making layer | Physical property |
| Speculative extension | Explicitly exploratory | Canonical empirical fact |

A PhaseNav vector is a computational representation. A vector similarity score cannot overwrite explicit ontology relations, source provenance, or epistemic status.
